# Artigos do MOBO TECH

Adicione arquivos `.md` nesta pasta. O esquema fica em `../content.config.ts` (na raiz de `src/`, arquivo `src/content.config.ts`). Exemplos de campos:

```yaml
---
title: "Título claro do artigo"
description: "Resumo original em até 180 caracteres."
category: "maker-diy"
author: "MOBO TECH"
pubDate: 2026-01-01
tags: ["projeto", "guia"]
draft: true
---

Conteúdo revisado em Markdown.
```

Mantenha `draft: true` enquanto o texto não estiver apurado, com compatibilidade, limitações, riscos e fontes verificadas. Altere para `false` apenas quando estiver pronto para publicação. A data acima é um exemplo de formato, não uma data editorial real.
