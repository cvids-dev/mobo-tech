# Acompanhamento do MOBO TECH

## Base Astro e homepage
- [ ] Migrar a página estática para Astro com HTML semântico, layout compartilhado e saída estática para Cloudflare Pages.
- [ ] Preservar a identidade futurista escura, melhorar a marca MOBO TECH e priorizar Maker, DIY e reaproveitamento.
- [ ] Manter responsividade para celular, tablet e desktop; menu mobile funcional; busca e filtros locais; acessibilidade por teclado e movimento reduzido.
- [ ] Não apresentar pautas editoriais ou cartões de exemplo como notícias ou artigos publicados.

## Conteúdo e navegação
- [ ] Definir artigos em Markdown com campos validados para título, resumo, categoria, autor, datas, capa, tags e status de rascunho.
- [ ] Publicar rotas de artigos apenas para entradas explicitamente marcadas como publicadas.
- [ ] Criar navegação para categorias, busca, sobre e contato.
- [ ] Criar páginas de política de privacidade, cookies e termos, e revisá-las antes de publicação.

## SEO e desempenho
- [ ] Incluir metadados por página, Open Graph, dados estruturados, URLs amigáveis, sitemap XML e robots.txt.
- [ ] Não usar domínio canônico provisório como se fosse definitivo; configurar SITE_URL com o endereço pages.dev efetivo antes do deploy.
- [ ] Validar build estático, links, acessibilidade básica e carregamento leve.

## Integrações e publicação (pendente)
- [ ] Conectar GitHub ao Cloudflare Pages e configurar build `npm run build`, saída `dist` e deploy automático na branch escolhida.
- [ ] Configurar e testar newsletter apenas quando um provedor for escolhido e autorizado.
- [ ] Avaliar monetização e analytics apenas após conteúdo original, revisão editorial, privacidade e aprovação das plataformas.
- [ ] Não alterar serviços nem containers do servidor doméstico.
